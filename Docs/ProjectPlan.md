
# Project Plan

## Project Overview

The goal of this project was to develop a Smart Home Automation (SHA) system using a custom application-layer protocol over TCP.

The project was planned as one sprint, from November 20 to November 24, 2026.

## Development Plan

| Period | Planned Work |
|---|---|
| November 20–22 | Plan the project, divide responsibilities, and begin development. |
| November 23 | Implement and integrate the main components. |
| November 24 | Complete documentation, testing, and video presentation. |

## Collaboration

We planned to use GitHub for version control and work on separate parts of the application.

Because the two active group members worked together in the same location, communication and task distribution were handled verbally rather than through formal GitHub issues.

For more details about our actual progress, meetings, completed tasks, and retrospective, see the [Sprint Report](Sprint.md).
